## О себе

Начинающий системный аналитик. Нахожусь на последнем курсе Тюменского государственного университета по направлению «Экономика» с IT-уклоном. Прошла профессиональную подготовку на курсе **GetAnalyst**, где освоила полный цикл системного анализа на практике. 

В рамках обучения работала над учебным проектом **U‑Verse** — образовательная платформа для взрослых. Отвечала за несколько ключевых направлений: структуру отзывов, процессы технической поддержки, подключение преподавателей, интеграции с внешними сервисами (Pruffme, RaifPay), проектирование базы данных и разработку всей сопутствующей документации.

**Ключевые компетенции:**
- Разработка требований к продукту на основе целей и стратегии бизнеса
- Сбор требований с заказчика и других заинтересованных сторон
- Анализ и приоритизация бизнес-требований
- Документирование пользовательских требований (User Story) и пользовательских сценариев
(Use Cases)
- Разработка ФТ и НФТ|
- Документирование и спецификация требований к реализации системы
- Проектирование интеграций: REST API
- Тестирование АРІ в Postman |
- Постановка задач на БД, Backend (API), Frontend
- Подключение к БД (PostgreSQL), работа с SQL
- Создание интерфейсов в Figma

**3. Подключение преподавателей к платформе**

*Задача:*  
Разработать сценарий регистрации, верификации и онбординга преподавателей на платформу.

*Решение:*  
Разработала полный сценарий регистрации и онбординга преподавателей. Спроектировала анкету преподавателя и структуру профиля. Описала процесс верификации и модерации преподавателей. Создала модель данных для профиля преподавателя и его связей с курсами и потоками.

*Артефакты:*
Не буду добавлять примеры работ, чтоб не переполнять информацию. 

**4. Интеграция с Pruffme (вебинарная платформа)**

*Задача:*  
Автоматизировать создание вебинарных комнат при планировании онлайн‑занятий.

*Решение:*  
Спроектировала интеграционный слой между U‑Verse и Pruffme. Разработала ТЗ на создание вебинарных комнат. Спроектировала маппинг данных между системами. Разработала UML-диаграмму последовательности, описывающую полный цикл. Описала требования к логированию и мониторингу.

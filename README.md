## О себе

Начинающий системный аналитик. Нахожусь на последнем курсе Тюменского государственного университета по направлению «Экономика» с IT-уклоном. Прошла профессиональную подготовку на курсе **GetAnalyst**, где освоила полный цикл системного анализа на практике. 

В рамках обучения работала над учебным проектом **U‑Verse** — образовательная платформа для взрослых. Отвечала за несколько ключевых направлений: структуру отзывов, процессы технической поддержки, подключение преподавателей, интеграции с внешними сервисами (Pruffme, RaifPay), проектирование базы данных и разработку всей сопутствующей документации.

**Ключевые компетенции:**
- Разработка требований к продукту на основе целей и стратегии бизнеса
- Сбор требований с заказчика и других заинтересованных сторон
- Анализ и приоритизация бизнес-требований
- Документирование пользовательских требований (User Story) и пользовательских сценариев
(Use Cases)
- Разработка ФТ и НФТ
- Документирование и спецификация требований к реализации системы
- Проектирование интеграций: REST API/SOAP API, вебхуки, очереди сообщений (Kafka/RabbitMQ)
- Тестирование АРІ в Postman/Swagger
- Постановка задач на БД, Backend (API), Frontend
- Подключение к БД (PostgreSQL/SQLite), работа с SQL
- Создание интерфейсов в Figma
